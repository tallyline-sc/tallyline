# Reviewed OCR research data

This directory contains the unchanged canonical Tiny dictionary and the public, revision-bound Tiny/Medium model catalogue. The model weights remain external research data; neither Cargo nor CI downloads them. Both Medium weights exceed the repository's 50 MB asset limit. Small uses the unchanged baseline in `../small/`.

`provenance.json` records official Hugging Face revisions, sizes, SHA-256, card/config hashes and dictionary bindings checked on 2026-11-02. All four author heads were last modified on 2026-06-18, outside S-7's seven-day cooldown. Cards declare Apache-2.0; the existing pinned PaddleOCR licence and NOTICE attribution apply. No conversion was performed. Static ONNX inspection found standard-domain operators, no external tensors, detector IR 10/opset 14 and recogniser IR 6/opset 11. This does not establish runtime compatibility or numerical correctness.

Tiny's 6,904 ordered dictionary entries match every author configuration index. The 27,156-byte canonical file has SHA-256 `c5cbe34ef40c29c4df07ed012bf96569cb69a2d2a01a07027e9f13cb832bd9cd`. Small and Medium use the unchanged 18,708-entry `../small/ppocrv6_dict.txt`, SHA-256 `b5f2bfe2bdd9448429e3e82b51c789775d9b42f2403d082b00662eb77e401c5d`. Blank zero and appended space give 6,906/18,710 classes. Dictionaries are never reconstructed from YAML, sorted or deduplicated.

The typed research profile identifies detector and recogniser independently, permitting nine explicit pairs. All use the named portable DB/bilinear arithmetic, BGR preprocessing, recognition height 48, mask threshold 0.2, unclip 1.4 and a bounded 1,000-contour cap. Tiny detection uses box threshold 0.4; Small/Medium use 0.45. The upstream 3,000-candidate limit and OpenCV arithmetic are not claimed. Existing Small behaviour and `ppocr-small-portable-db-bilinear-v1` remain unchanged.

`ResearchOcrAssets::load` hashes each selected absolute data file in detector/recogniser/dictionary order before native initialisation. It retains the exact hashed model bytes for all session creation and reopening. Filenames and model paths do not select executable code, runtimes or plugins. All native environment, host/DLL/CRT and one-load-token checks remain mandatory. Research assets retain model snapshots until dropped; resource evaluation must count this memory as well as native sessions.

These are developer experiments, not a production/default replacement, automatic fusion or complete installation profile. No separate Ollama or Python prerequisite is added. Before recommendation, evaluate individual readers and independent cross pairs on frozen inputs, then quantify joint errors and resources on real weak/strong hardware. Agreement is not truth or calibrated confidence. Full-corpus field/layout metrics, pool/admission/cancellation/tiling, Linux and complete delivery without a separate CRT prerequisite remain open. See the [probe guide](../../../app/examples/README.md).

Nine pair configurations contain only three recogniser weight sets. Shared detections and related family/training prohibit treating them as nine independent witnesses or majority votes; use them to isolate localisation, reading and resource changes.
